# Security

Please report a vulnerability privately: this repository's **Security** tab → **Report a vulnerability**
(GitHub's private vulnerability reporting). Not in a public issue.

Worth reporting: anything that lets someone reach an app, a file or a sign-in they shouldn't, from the internet,
the LAN or another NetBird peer; anything that puts a secret into a log, a command's output, an answers file or
the setup app's window; anything that turns a setup step into a wipe it didn't announce.

If the hole is in an app itself (Paperless, Immich, Authentik, …), report it to that project too.

There are no releases to patch yet: fixes go to `main`.
